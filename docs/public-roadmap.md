# Public Roadmap Summary

Telltale is an open-source detection layer for AI coding agents. The public
roadmap should focus on the durable user-facing story: discover local agent
session stores, normalize their content, apply deterministic detections, emit
SIEM-friendly telemetry, and keep privacy and evidence handling explicit.

Near-term public milestones should stay at the level of product capability,
not internal execution detail:

- broaden supported source adapters where fixture coverage exists;
- refine rule quality, metadata, and redaction behavior;
- keep emitted telemetry stable for downstream SIEM and analysis workflows;
- document supported operator workflows without exposing host-specific notes.

This summary exists so public-facing planning can remain concise and focused
on externally useful capabilities.

For the related public strategy and release notes summaries, see
`docs/public-strategy.md` and `docs/public-release-notes.md`.
